# Общие инструменты DragShift и Swipe4Rest

Общий выпуск: DragShift **files.15** / Swipe4Rest **0.1.1**. Расширения обработки файлов доступны в обеих программах; интерфейсы и профили раздельные. DragShift: **Shift → Инструменты**. Swipe4Rest: **Alt/Option → Обработать**.

## Переименование

Выберите файлы или папки → **Переименовать** (в Swipe4Rest — ветка **Файлы**). Добавьте правила сверху вниз. По умолчанию меняется имя без расширения. Таблица показывает исходное имя, новое имя и ошибки; новый вариант можно вписать вручную. Исключите ненужные строки галочками.

Есть вставка/удаление/замена текста, регулярные выражения с ограничением времени, регистр, нумерация, разрядность, очистка, транслитерация, даты, перестановка частей и шаблоны. Порядок: числа в имени, дата изменения от старых к новым или порядок добавления. Перетащенные папки переименовываются сами; содержимое автоматически не обходится. Папку и выбранные файлы внутри неё обрабатывайте отдельно.

Поля шаблона: `{name}`, `{ext}`, `{n:03}`, `{parent}`, `{modified:%Y-%m-%d}`, `{width}`, `{height}`, `{date_taken:%Y-%m-%d}`, `{artist}`. Недоступные метаданные показывают ошибку. Смена расширения меняет имя, а не содержимое.

**Сохранить правила** записывает JSON. **Импорт CSV** принимает два столбца `source,new_name` с полным путём или однозначным исходным именем. Разделители: запятая, точка с запятой или табуляция. **Экспорт CSV** сохраняет предпросмотр. Имена применяются только по кнопке **Переименовать файлы**.

Проверяются занятые имена, дубликаты, недопустимые символы и изменения после предпросмотра. Операция внутри исходных папок использует временные имена и журнал восстановления. **Отменить переименование** возвращает имена, если файлы не изменились. История позволяет просмотреть отмену или восстановить незавершённую операцию после перезапуска. Символические ссылки и точки соединения не переименовываются; ярлык Windows `.lnk` переименовывается как файл ярлыка.

## Инверсия и реверс

**Правка → Инверсия цветов** меняет RGB, сохраняя прозрачность. Применяется ко всем выбранным изображениям и кадрам анимации.

**Реверс** создаёт новый файл с обратным порядком кадров и их длительностей. GIF, WebP и PNG-анимации сохраняют формат и цикл. Видео сохраняется в MP4, прозрачное VP9 — в WebM; звук видео также обращается. Нужен запас диска для промежуточных данных. Реверс больших изображений ограничен лимитом редактора анимаций; видео обрабатывается частями.

В Swipe4Rest инверсия и реверс также добавляются шагами цепочки. Переименование — отдельный завершающий инструмент с собственным предпросмотром и отменой.

## Distort и звук

Ключевые точки задают силу видеоэффекта во времени. **Волнообразный питч звука** задаёт диапазон повышения/понижения высоты исходного звука; размах следует тем же точкам. При 0 звук остаётся исходным. Это самостоятельный эффект, а не обещание точного воспроизведения закрытого Telegram-сервиса.

**Кадр предпросмотра** меняет только отображаемый момент. **Начало/конец сохранения** определяют участок готового ролика; его длительность указана отдельно. **Всё видео** возвращает полный диапазон. PNG сохраняет один кадр, MP4/WebM/GIF — весь указанный участок. Ограничение большой стороны сохраняет пропорции и не увеличивает исходник.

## Melt: распад и восстановление

Левая ручка отмечает начало распада A, правая — первый восстановленный кадр B. Маркер склейки неподвижен; числовые поля настраивают границы точно. В серии каждый стык независим; соседние интервалы не должны пересекаться.

Создайте **предпросмотр**, затем проигрывайте или перематывайте реально обработанный переход внутри окна. После изменения настроек прежний результат помечается устаревшим. Предпросмотр уменьшен и без звука, но охватывает весь эффект.

**Обратное восстановление Melt** — экспериментальное соединение прямого и обратного датамошинга. Используются два искажённых потока без растворения в чистое видео. Нужен участок до стыка и чистые кадры перед ним. Классический вариант сохранён. Универсальная плавность для любого движения не гарантируется: сравнивайте обработанные варианты перед сохранением.
